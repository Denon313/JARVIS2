سرویس‌های جایگزین

در این نسخه یک سرویس فعال تنظیم می‌شود. برای جایگزینی، اطلاعات سرویس دیگری را وارد کن. برای fallback واقعی باید چند سرویس و محدودیت‌های CORS آن‌ها جداگانه پیاده‌سازی شوند.

این یک سایت استاتیک است؛ کلید API در مرورگر امن نیست و هرگز نباید آن را در کد HTML قرار بدهی. برای استفاده عمومی، backend امن با نگهداری کلید در سمت سرور لازم است.
